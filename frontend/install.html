Install by scanning this QR code

Android & iPhone · no cable needed

  1. Open the camera on your phone and point it at the QR code, then tap the link that appears.
  2. Android: tap Download for Android, open PlanetWatch.apk and tap Install (allow “Install unknown apps” if asked).
  3. iPhone: tap the Share button in Safari, then Add to Home Screen.
  4. Make sure your phone is on the same Wi‑Fi as this computer.

Install with a USB cable

Android phones · connect to this computer

  1. On your phone open Settings → About phone and tap Build number 7 times to unlock Developer options.
  2. Go to Settings → System → Developer options and switch on USB debugging.
  3. Connect your phone to this computer with a USB cable.
  4. Scroll down from the top of your phone's screen, tap the “Charging this device via USB” notification and select File transfer.
  5. Tap Allow when your phone asks “Allow USB debugging?”.
  6. When the green check appears, click Install app.
